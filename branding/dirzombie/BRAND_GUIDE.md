# DirZombie Brand Guide

## Essence

DirZombie is not a generic horror mark. It is a destination with teeth:

- a directory people can find
- a dead listing pulled back into motion
- a place marker that behaves like a tombstone and a doorway
- the `Z` as the scar, shortcut, and claim

## Core Claim

The directory that refuses to die.

## Logo System

- `logo/dirzombie-mark.svg`: primary symbol
- `logo/dirzombie-wordmark.svg`: pure wordmark
- `logo/dirzombie-lockup-horizontal.svg`: primary default lockup
- `favicon/favicon.svg`: favicon and browser tab mark using the same sigil
- `social/profile-square-1080.svg`: universal avatar master

## Palette

- Grave Black `#050607`
- Bone White `#F4F0E3`
- Infection Green `#A7F05C`
- Burial Violet `#8C57FF`
- Arterial Red `#FF3B52`

Use Grave Black as the field, Bone White for structure, Infection Green for the undead signal, Burial Violet for depth, and Arterial Red as the edge accent.

## Usage Rules

- The mark should be used as the favicon, avatar, and app icon so the identity stays unified.
- Do not replace the `Z` with a plain letter; the cut-through shape is the recognizable part.
- Keep clear space around the mark equal to at least the green eye diameter.
- Use the full lockup where the claim needs to be visible.
- Use the mark alone for profile icons, favicons, and tight UI surfaces.

## Export Notes

PNG exports are generated from the SVG masters with `rsvg-convert` when local tooling is available.
