How it actually runs

operations, not slideware

Self-hosted, on purpose

Four domains served from hardware I own, each through its own Cloudflare named tunnel with its own credentials — a tunnel can only serve a zone in the same account, so they cannot share a daemon. Processes are supervised by PM2 with a boot-resurrect path.

Built to degrade, not fall over

Hot endpoints run behind deadline middleware and a TTL cache. When the database is slow, the API returns a partial payload flagged degraded and the client renders what it has. A slow query is a smaller answer, never a white screen.

Mobile is the design target

Every surface is laid out at 375px first and expanded. Fixed chrome reserves its own gutter instead of floating over content, all type is fluid, and no content depends on JavaScript to become visible. This page included — disable scripts and nothing is lost.
